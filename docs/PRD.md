# 产品设计文档：PPT 方案自动排版与配图工具

| 项目 | 内容 |
| --- | --- |
| 版本 | v1.0（MVP 范围） |
| 日期 | 2026-11-01 |
| 状态 | 方向已确认，进入 MVP 实施 |

## 1. 背景与定位

历史方案沉淀了大量可复用的版式与素材，但每次做新方案仍要人工重复排版、找图、调字号。
本工具把"历史方案"变成两类资产——**模板页**与**图片图库**，再根据文案和**方案模板**
自动生成新方案 PPT。

定位：面向方案策划/售前人员的**半自动排版工具**，不是通用 PPT 生成器。
产出物是"可交付初稿"，人工在此基础上微调，而不是零人工。

## 2. 目标用户与场景

| 角色 | 场景 | 诉求 |
| --- | --- | --- |
| 方案策划 | 研学/行程类方案提报 | 30 分钟内出一版能看的初稿 |
| 售前/商务 | 客户临时要方案 | 复用成熟版式，风格统一 |
| 设计支持 | 维护模板资产 | 模板页可沉淀、可组合、可迭代 |

## 3. 核心概念

| 概念 | 定义 |
| --- | --- |
| 模板页（Slide Template） | 从历史方案中抽取并清空内容的单页版式，保留形状几何、配色、字体、图片槽位 |
| 板块（Section） | 方案模板中的一个语义段落，如封面、行程亮点、研学行程汇总、关键数据、报名须知；每个板块挂若干模板页 |
| 方案模板（Deck Template） | 板块的有序组合，三级结构：方案模板 → 板块 → 页面 |
| 方案（Deck） | 一次生成的产物，= 文案 + 方案模板 + 配图决策 |
| 图库（Gallery） | 从历史方案抽取的图片集合，带来源、尺寸、主色、标签等元数据 |
| 中间表示（deck.json） | 排版引擎的唯一输入，描述页序、字段值、图片槽位与溢出策略 |

## 4. 核心流程

```text
历史方案(.pptx) ──解析──▶ 模板页 + 图库
                              │
文案(结构化) ──▶ 字段绑定 ──▶ 排版引擎 ──▶ deck.pptx + 逐页预览
                              ▲
                    图库命中 / 手动指定图片
```

五步：**解析沉淀 → 选方案模板 → 上传 Markdown 文案 → 自动排版配图 → 渲染验收**。

文案不逐页手填：选定方案模板后，系统按板块生成对应的标准 Markdown 文案模板
（下载 .md → 填写 → 上传），解析结果回填到各板块字段。

## 5. 功能模块

### 5.1 模板库管理

- 解析历史方案，按页抽取版式，清空文本与图片，生成模板页。
- 模板页属性：页型（封面/亮点/行程/汇总/报价/须知）、形状与占位符、缩略图、来源方案。
- 抽页策略：不追求 100% 还原，不支持的形状（SmartArt、图表、组合）降级为图片占位。
- 页型分类：规则粗排 + 人工确认一次。

MVP：离线脚本 + 目录结构 + 缩略图，人工确认后入库。
后置：可视化增删改、去重合并、版本管理。

### 5.2 方案模板管理

编辑器为三列结构，均为增删改一体：

| 列 | 内容 | 可做 |
| --- | --- | --- |
| 方案模板列表 | 全部模板及板块/页数 | 新建、删除、切换 |
| 板块列表 | 当前模板的板块及顺序 | 新建板块、删除、上移下移 |
| 页面 | 当前板块下的模板页 | 添加页、删除、上移下移 |

- 板块预设：封面、行程亮点、研学行程汇总、关键数据、报名须知；板块自带类型，
  页型与板块类型不一致时给出提示。
- 内置模板：封面模板、行程亮点模板、研学行程汇总模板、完整方案模板。
- 保存后即可用于新建方案（配置即模板，先不做拖拽）。

MVP：JSON 配置 + 三列编辑 + 增删保存；提供 4 个内置模板。
后置：可视化拖拽、条件分支（按方案类型选页）、主题/品牌切换。

### 5.3 排版引擎

- 字段 → 占位符绑定（按 placeholder name / shape name 约定）。
- 文本溢出策略：字数预算 → 字号阶梯 → 行距微调 → 超预算拆页。
- 图片槽位按目标比例裁剪，保持视觉重心。
- 输出 `pptx` 与逐页渲染图，供人工验收。

文案输入为按板块生成的 Markdown 模板，解析后按板块取页填充。

MVP：上述全部，规则固定、可配置项收敛为配置文件。
后置：自适应字体缩放、图文混排重排、多母版。

### 5.4 自动配图

- 优先级：**手动指定 > 图库命中 > 待配图清单**（网络图源为后置）。
- 图库检索：关键词 + 宽高比 + 主色匹配；MVP 尾期引入向量检索。
- 缺图不阻塞出稿：输出占位色块 + 待配图清单（含建议关键词），补图后重跑。

MVP：图库索引 + 关键词检索 + 优先级链 + 清单。
后置：网络图片搜索/下载、去水印、版权校验、人脸构图裁剪。

## 6. 关键设计决策

1. **中间表示先行**：所有能力围绕 `deck.json` 建设，排版引擎不直接读 docx/自然语言。
2. **结构化文案优先**：MVP 输入是符合 schema 的 YAML/JSON，不做自然语言整篇生成，
   出错可定位到字段。
3. **配置即模板**：方案模板 = 有序页引用 + 字段映射的配置文件，先跑通再谈可视化编辑。
4. **降级而非失败**：任何解析不了的元素降级为占位，保证流程总能出稿。

## 7. MVP 范围与里程碑

| 里程碑 | 周期 | 内容 | 验收标准 |
| --- | --- | --- | --- |
| M1 排版主链路 | 2 周 | deck.json、抽页脚本、三列方案模板编辑器、Markdown 文案模板与解析、字段绑定与溢出策略、pptx+预览输出 | 上传 1 份按模板填写的 md，生成 6 页以上，字段全落位，无文本溢出 |
| M2 图库与配图 | 2 周 | 图库抽取与索引、检索、优先级链、待配图清单 | 图库 500 张，自动配图覆盖率 ≥ 70% |
| M3 真实回归 | 2 周 | 10 份历史方案端到端回归，修模板与溢出规则 | 单份生成 < 30s，人工修改 < 30 分钟，可交付度评分 ≥ 4/5 |

## 8. 非目标（本期不做）

- 自然语言整篇生成、通用 PPT 生成
- 网络图片搜索、下载、去水印、版权校验
- 可视化模板编辑器 / Web 应用
- 母版继承、SmartArt、图表、动画
- 多品牌主题切换、多人协作与权限

## 9. 成功指标

| 指标 | 目标 |
| --- | --- |
| 单份方案生成耗时 | < 30 秒 |
| 人工修改耗时 | 从数小时降至 < 30 分钟 |
| 字段落位准确率 | ≥ 98% |

| 文本溢出率 | < 5% 页面 |

## 10. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| `python-pptx` 对复杂形状支持有限 | 模板页还原度不足 | 降级为图片占位；优先选用形状简单的历史页 |
| 字体缺失导致预览失真 | 引擎正常但验收不过 | M1 建立字体替换表，锁定 3–4 款字体 |
| 文案字数不可控 | 文本溢出返工 | 硬性字数预算 + 拆页规则，不给"自适应"留空间 |
| 页型分类不准 | 方案模板组合错页 | 人工标注一次，规则粗排 + 复核 |
| 图库素材质量参差 | 配图不可用 | 入库带标签与评分，检索时过滤低质 |

## 11. 技术选型（初步）

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 解析与生成 | Python + `python-pptx` | 读写 pptx，形状级操作 |
| 渲染验收 | LibreOffice（`soffice --convert-to pdf/png`） | 逐页预览，避免字体缺失误判 |
| 文案输入 | YAML + JSON Schema | 结构校验，错误定位到字段 |
| 数据存储 | 文件系统（JSON + 图片目录） | MVP 不引入数据库 |
| 检索 | 关键词 + 元数据过滤 | 后续接 embedding |

## 12. 目录规划

```text
src/parse/       # 抽页、抽图、页型识别
src/template/    # 模板页 -> 方案模板组合
src/layout/      # deck.json -> pptx，绑定与溢出
src/images/      # 图库索引、检索、配图决策
src/render/      # 逐页渲染与验收
schemas/         # deck.json / content.schema.json
samples/         # 脱敏历史方案与期望输出
docs/            # 产品与设计文档
tests/           # 管道回归与仓库校验
```
